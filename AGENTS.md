# AGENTS.md

Instructions for AI coding agents. Complement to README.md.

## Quick Commands

```bash
bun run typecheck              # typecheck
bun run lint                   # ESLint (flat config, type-aware)
bun run check                  # every *.check.ts self-check
bun run typecheck && bun run lint && bun run check  # all
```

No test framework. `*.check.ts` files are assert-based self-checks run by `scripts/check.ts`.

## Project

Expo 58 + React Native 0.88. **Android-only** (no iOS/web). File-based routing via `expo-router`.

- **Package manager:** bun. Use `bun add`, `bunx expo install`, `bun install --frozen-lockfile` in CI. Never npm.

- **State:** Zustand stores in `src/stores/`. Use individual selectors (`useStore(s => s.field)`) — never full store subscription.
- **Imports:** `@/*` maps to `./src/*`
- **Styling:** uniwind + Tailwind CSS v4. `global.css` entry: `@import "tailwindcss"; @import "uniwind";`. `uniwind-types.d.ts` is generated by Metro — commit it, don't edit it.
- **TypeScript:** strict, `noUnusedLocals`, `noUnusedParameters`, `noImplicitReturns`, `noFallthroughCasesInSwitch`, `forceConsistentCasingInFileNames`

## ESLint (type-aware)

- `@typescript-eslint/no-floating-promises` (error) — must `void`, `await`, or `.catch()`
- `@typescript-eslint/prefer-nullish-coalescing` (error) — `??` over `||`
- `@typescript-eslint/switch-exhaustiveness-check` (error)
- `react-hooks/exhaustive-deps` (warn)
- `no-duplicate-imports` (error), `no-var` (error)

## CI/CD Gotchas

- `android/` not tracked — generated by `bunx expo prebuild --platform android`
- `setup-android@v3` no longer accepts `api-level` or `build-tools`
- `react-native-worklets` required peer of `react-native-reanimated` 4.x
- EAS prod build: `buildType: "apk"` (NDK not pinned — local builds ignore the `ndk` field anyway)
- Signing: EAS-managed credentials (remote) — only `EXPO_TOKEN` needed in CI; keystore lives in EAS (`eas credentials`)
- `eas build --local` runs prebuild internally — no explicit prebuild step in CI
- Version: `bun run release X.Y.Z` bumps `app.json` (`expo.version`) and `package.json`, commits, tags and pushes
- `android.versionCode` is not in the repo — `appVersionSource: "remote"` plus `autoIncrement: true` in `eas.json` lets EAS own it
- `bun install` respects `trustedDependencies` — `unrs-resolver` is listed there, without it its native binding never builds and ESLint import resolution fails
