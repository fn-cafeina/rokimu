## Quick Commands

```bash
bun run typecheck              # typecheck
bun run lint                   # ESLint (flat config, type-aware)
bun run check                  # every *.check.ts self-check
bun run typecheck && bun run lint && bun run check  # all
```

No test framework. `*.check.ts` files are assert-based self-checks run by `scripts/check.ts`.

## Project

Expo 58 + React Native 0.88. **Android-only** (no iOS/web). File-based routing via `expo-router`.

- **Package manager:** bun. Use `bun add`, `bunx expo install`, `bun install --frozen-lockfile` in CI. Never npm.
- **State:** Zustand stores in `src/stores/` (catalog, details, search, saved, history, downloads, player, settings, update). Use individual selectors (`useStore(s => s.field)`) — never full store subscription.
- **Transport:** source requests go through the hidden WebView worker (`src/services/webview.ts` + `src/components/app/WebViewWorker.tsx`), so the page's cookie jar (HttpOnly included) and Cloudflare clearance do the work. `fetchWithSession` in `src/services/source.ts` is the native path for the same origin. A foreign video host's rejection never triggers a session wash.
- **Streams:** `src/services/extractors.ts` resolves Delta through its Byse AES-GCM API and Epsilon through a LuluStream embed. `src/utils/serverOrder.ts` reorders the ladder by the user's preferred server; playback plays the chosen server or fails, it never substitutes another.
- **Downloads:** segments are fetched 5 at a time, 4 for Epsilon: expo-file-system downloads through OkHttp's `Dispatcher` (default `maxRequestsPerHost = 5`), so a bigger pool only queues, and Epsilon's CDN answers 429 above four. `segmentConcurrencyFor` in `src/utils/serverOrder.ts` owns that number. Segments stay encrypted; the player decrypts them.
- **Browse:** `/directorio` takes `genre`, `type`, `status`, `year` and `page` in the same request and answers with 28 cards plus a `Página X/Y` footer and a `rel="next"` link only when another page exists. The taxonomy paths (`/genero/<slug>`, `/anio/<year>`) ignore any extra param, so filtering never uses them. The search API (`/api/anime/search?q=`) takes only `q` and ignores `page`, so text and filters never combine.
- **Imports:** `@/*` maps to `./src/*`
- **Styling:** uniwind + Tailwind CSS v4. `global.css` entry: `@import "tailwindcss"; @import "uniwind";`. `uniwind-types.d.ts` is generated by Metro — commit it, don't edit it.
- **TypeScript:** strict, `noUnusedLocals`, `noUnusedParameters`, `noImplicitReturns`, `noFallthroughCasesInSwitch`, `forceConsistentCasingInFileNames`

## CI/CD Gotchas

- `android/` not tracked — generated by `bunx expo prebuild --platform android`
- Toolchain is pinned in the workflows: bun `1.4.4`, node `22.13`, `eas-cli@27.4.1`, `expo-doctor@1.21.8`. A bump belongs in `.github/workflows/`, not in the README.
- `setup-android@v3` no longer accepts `api-level` or `build-tools`
- `react-native-worklets` required peer of `react-native-reanimated` 4.x
- EAS prod build: `buildType: "apk"` (NDK not pinned — local builds ignore the `ndk` field anyway)
- Signing: EAS-managed credentials (remote) — only `EXPO_TOKEN` needed in CI; keystore lives in EAS (`eas credentials`)
- `eas build --local` runs prebuild internally — no explicit prebuild step in CI
- Version: `bun run release patch|minor|major|X.Y.Z` bumps `app.json` (`expo.version`) and `package.json`, commits, tags and pushes; the words resolve like `npm version`
- `android.versionCode` is not in the repo — `appVersionSource: "remote"` plus `autoIncrement: true` in `eas.json` lets EAS own it
- `bun install` respects `trustedDependencies` — `unrs-resolver` is listed there, without it its native binding never builds and ESLint import resolution fails
- `expo-font` is a required peer dependency of `@expo/vector-icons` (used across the UI). Removing it fails `expo-doctor` in CI ("Missing peer dependency: expo-font") even though nothing imports `expo-font` directly. Do not remove it; direct imports are not the criterion for Expo native peer deps.
